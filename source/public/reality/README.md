# Gắn tác phẩm thật vào Reality Rewrite

Đặt file vào thư mục này rồi khai báo trong `src/reality/tracks.ts`:

- `audioSrc: '/reality/mua-ha-thu-18.mp3'`  — bản thu thật (đoạn highlight 45–90 giây qua `highlight.start/dur`)
- `videoSrc: '/reality/mua-ha-thu-18.mp4'`  — video; được chiếu lên các "khung ký ức" bay quanh thế giới và lên cửa sổ tòa B1 (UEH)

Khi file tồn tại, nhãn DEMO tự biến mất và nhạc/video thật thay thế bản phối thủ tục.
Lưu ý: trong dữ liệu portfolio hiện tại quyền rehost của cả hai bài đang là `not_granted` — hãy xác nhận quyền trước khi đưa file thật lên website công khai.
