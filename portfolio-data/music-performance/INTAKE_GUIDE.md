# SHOWTIME — MUSIC & PERFORMANCE content intake
Status: OPEN / user has not declared submission complete. This is a creative exhibition inventory, NOT only a job CV.

## Scope
Collect works across singing, musical performance, covers, original recordings, live stages, experimental/AI-aided music, collaborations, and any musical artifact the owner wants to exhibit. One work can appear in several collections without duplicating source assets.

## Minimum metadata to request from owner PER ITEM
1. Working title / song or performance name (exact spelling).
2. Category: cover / original / stage live / studio / rehearsal / AI-assisted / mashup / other.
3. Owner's verified contribution(s): vocal / performer / composition / mixing / arrangement / editing / production / other; never infer role from an image, lyrics or credits.
4. Year (or approximate date); venue / event if it was a live show.
5. Link to existing public audio or video, OR indicate an unpublished local file exists; can be missing at first intake.
6. Public-display preference (okay to feature, archive-only, or private) when relevant.

## Useful optional assets
- Audio: MP3/WAV/M4A (only owner-authorized recordings), platform links, stems, alternate takes, instrumental, version history.
- Video: live performance clip, rehearsal, music video, camera angles or platform embed.
- Images: cover, poster, stage photos, backstage and rehearsals, recording-room stills.
- Creative process: ideas, arrangement notes, demo, written annotations, project screenshots, session workflows, collaboration credits.
- Artistic narrative: why chosen, mood, memorable moment, personal reflection in the owner's own words.
- Evidence: credited release, performance program, awards, feedback, release metadata/links.

## Proposed website presentation
1. **THE LISTENING ROOM:** media deck; user-picked recordings with waveform/cover and credits. No autoplay.
2. **LIVE STAGE:** performance clips, stage photography, lighting/camera shifts derived from actual media.
3. **THE RECORDING TABLE:** process artifacts, demos and version comparisons only when genuine source material exists.
4. **THE ARCHIVE:** everything else, including small experiments, grouped chronologically or by form.

Each item should support `SHOW` (play/watch), `STORY` (owner notes), `PROOF` (credits/links), and `PROCESS` only when available. Do not force process artifacts for a simple live cover.

## External-media rules
Publicly viewable is not necessarily licensed for download, rehosting, remix or embedding. Prefer original-host platform embeds where available; record `rights`, `source`, `owner_credits`, and `embed_approved`. Do not reproduce full non-user-written song lyrics.
