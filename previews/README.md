# Composition previews

**These are not the deliverable screenshots.**

Godot is not installed in this environment, so these images are generated by
`tools/preview_studies.py`, which projects each study's real world-space
geometry through that study's real canonical camera.

What they show faithfully:

- camera position, orientation and field of view
- every object's true measured footprint and position
- depth ordering, occlusion and overlap
- where the reserved portfolio surfaces land in frame

What they do **not** show:

- lighting, shadows, ambient occlusion
- materials, colour, roughness
- tonemapping or post-processing

Blue = reserved portfolio content surfaces. Cream = hero objects
(display, corkboard, spotlight fixture, chair). Brown = built desk/shelf
surfaces. Dark grey = the room shell.

Engine-rendered screenshots from the canonical cameras are the next step and
require a Godot 4 binary.
